# Phase 2 — ML Detector: Design & Evaluation Protocol

Defender-side companion to the Phase-1 FDI characterisation. The threat model is
**frozen** (stealthy `a = Hc` min-footprint FDI on the islanded droop microgrid,
per-step i.i.d., PF and QV channels); this document specifies only the detector
and its validation. Target bar: IEEE TSG/TII reviewer.

## 1. What makes the attack detectable at all

The stealthy FDI is consistent with the *measurement model* (`z + Hc` is a valid
measurement of state `x + c`), so any residual test is blind by construction.
It is **not** consistent with the *operational manifold*: real operating points
satisfy the droop equilibrium (proportional P-sharing across DERs, Q-V droop
tying DER voltages to their reactive injections) and the load's spatial/temporal
structure. The biased state `x + c` violates these. Hence two detector families:

- **Physics-oracle baseline** (needs droop parameters + setpoints): droop-
  consistency residuals computed from the WLS estimate. Shows the information
  exists in `z`; not the headline because it requires exact vendor/droop data
  and assumes no legitimate setpoint changes.
- **Data-driven detector** (headline): learns the normal manifold from
  attack-free operation; needs no network/droop model.

## 2. Detector families

| Family | Models | Trains on | Role |
|---|---|---|---|
| Residual BDD | chi-squared J vs tau (Phase-1 logs) | — | incumbent, blind |
| Physics oracle | max abs droop-consistency residual | clean val (threshold only) | information upper bound, model-based |
| Semi-supervised | PCA-SPE, PCA-Hotelling-T2, Autoencoder (MLP), OC-SVM, Isolation Forest | normal steps only | **headline** |
| Supervised | LogReg, Random Forest, HistGradientBoosting, MLP | labelled normal+stealthy-FDI | upper bound with labels; generalization stress-tested |

All operate per step on quantities the EMS already has. Alarm thresholds for
score-based detectors are set on **clean validation data at 1% FPR** — the same
alpha as the BDD, so comparisons are apples-to-apples.

## 3. Feature sets (ablation)

- **F1 raw**: the 130-dim measurement vector z (standardized on train stats).
- **F2 physics**: derived from the detector's own iterative WLS estimate:
  V-hat profile, WLS objective J, per-DER implied frequency offsets
  `df_i = m_p_i (Pset_i − Pg_i)` (equal across DERs at true equilibria; their
  spread is a droop-consistency residual), Q-V droop residuals
  `V_hat(der_i) − (V_nom − n_q_i * Qg_i)`, total-injection balance, min/max V.
  DER output estimates use net injections plus the nominal load pattern scaled
  by the estimated total (operator knowledge; no oracle access).
- **F3 = F1 ∪ F2.**

**Deliberately excluded:** temporal deltas (z_t − z_{t−1}). The frozen attack
toggles i.i.d. per step, so Δ-features would detect the *toggling artifact*,
not the attack, and a persistent attacker defeats them. Discussed as a
limitation/extension instead — this avoids an overclaim.

## 4. Data protocol (leakage-proof)

Generated by `MATLAB/Phase2/GenerateDetectorData.m` — a derivative of the
frozen `SimulateMicrogridFDI.m` that adds a UCI-segment offset, output naming,
and extra logging (measurement vectors for the naive and limited-access attack
variants; stealth flags). Its identity with the frozen simulator is proven by a
**bit-for-bit** reproduction of `VectorDataset_PF_corrected/features_z.csv`
(seed 42, steps 3000, warmup 400, offset 0) before any new data is trusted.

UCI load file has 186,297 rows; all segments are disjoint:

| Split | Seed(s) | Offset | Logged steps | Purpose |
|---|---|---|---|---|
| TRAIN | 101 | 0 | 18,000 | semi-sup: normal steps; supervised: all |
| VAL | 105 | 40,000 | 4,000 | thresholds (clean steps @1% FPR), model selection |
| TEST | 201–205 | 80k–140k (15k apart) | 5 × 4,000 | headline metrics, t-CIs over 5 runs |
| MAG | 301 | 160,000 | 7 × 2,000 | magScale ∈ {0.2,…,1.4}: detection vs magnitude |

Both channels (PF, QV) at every row. Attack probability stays 0.25. Naive and
limited-access variant vectors are logged on TEST and MAG runs only.

Notes:
- Different splits get different load segments *and* different seeds — no
  shared load trajectory or noise stream between train and test.
- Random shuffling across time is never used; splits are whole runs.
- Normal steps are i.i.d.-equivalent to attack-free operation because the
  frozen sim carries no state across steps (setpoints reset from load each
  step); so semi-supervised training data comes from the normal-labelled steps
  of TRAIN. A **contamination study** re-trains the semi-supervised models with
  {0.5, 1, 2, 5}% unlabelled attacked steps mixed in.

## 5. Evaluation matrix

Primary metric: **TPR at the deployed threshold** (set once on clean val, 1%
FPR), reported with realized test FPR; plus ROC-AUC, PR-AUC. CIs: t-based
(n = 5 test runs) — the z-vs-t lesson from the Phase-1 audit (M-1) applies.

| Test | Question |
|---|---|
| In-distribution (TEST, magScale 1) | headline TPR@1%FPR vs BDD's ~1% |
| Magnitude sweep incl. below-training (0.2–0.8) | where does detection fail, and does the induced |real dev| there still matter? (plot TPR and impact vs magnitude together) |
| Naive same-norm injections | sanity: ML must also catch what BDD catches |
| Limited-access (70%) attacks | does ML cover the BDD-evading remainder (QV: ~18% evade)? report BDD ∪ ML combined coverage |
| Cross-channel (supervised only: train PF → test QV, and vice versa) | do labelled detectors overfit the attack family? |
| Contamination (semi-sup) | robustness to imperfect training hygiene |
| Feature ablation F1/F2/F3 | what do physics features buy? |

The BDD row uses Phase-1's own logged J and tau — no reimplementation.

## 6. Implementation

- Python 3.11, scikit-learn 1.8 (no GPU/torch dependency — reproducibility).
  Autoencoder = MLPRegressor(64-16-64, relu, adam, early stopping).
- Detector-side SE: full iterative Gauss-Newton WLS from flat start (ported
  from `_verify/mirror_check.py` numerics) — the detector does *not* reuse the
  simulator's linearization about the true state.
- Everything seeded; one driver script regenerates all results/figures/tables.

## 7. Honest-limitations register (goes in the paper)

- Single test system (33-bus), simulated data, no HIL.
- Attack non-persistence is a sim artifact; detector is per-step precisely so
  persistence does not matter, but temporal detectors remain future work.
- Semi-supervised threshold assumes an attack-free calibration window.
- Physics-oracle requires exact droop data; shown as bound, not deployment.
- Supervised results conditional on attack-family coverage (quantified by the
  cross-channel test rather than hand-waved).
